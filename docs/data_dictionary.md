# Candidate fields from official layer HTML

`OBJECTID` is the row ID; `PARCEL_NUMBER` is a parcel identifier; `Property_Type` includes the renderer value `Single Family Residence`; `DOCUMENT_DATE` is an ArcGIS date and the layer's time field; `INDICATED_SALES_PRICE` is a nullable string, not confirmed consideration; `BUILDING_SF`, `LOT_SIZE_SQFEET`, `NUMBER_OF_BEDROOMS`, `NUMBER_OF_BATHS`, `EFFECTIVE_YEAR_BUILT` are nullable numeric fields. Exact missingness, values, provenance, update timing, and eligibility remain unverified pending live scan. Raw owner or address fields are never logged or committed.
